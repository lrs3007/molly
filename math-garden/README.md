# 数学小花园

小学奥数教学 MVP，React + TypeScript + Vite 静态网站。开放一年级奥数班的植树、归一、和差、周期、平均数、和差倍、移多补少、平面图形计数和年龄问题，共48节动画课程、240段预制普通话讲解、66道带提示和解析的练习。其他年级展示筹备状态。

## 开发与验证

```sh
npm ci
npm run dev
npm test
npm run build
```

默认本地地址 http://127.0.0.1:5173 。生产文件输出到 `dist/`，可直接部署为静态网站。Node 22.18+ 可运行使用原生 TypeScript 类型剥离的测试脚本，推荐Node24+。

## 内容与动画

原三年级课程已归入一年级奥数班，课程与练习编号同步改为一年级。原四年级题目保留在 `src/courses/archive/grade-4.ts`，未加入课程注册表。浏览器学习记录会自动迁移：原三年级记录转入一年级，四年级记录保留为归档且不计入当前进度。现有配音复用历史资源，`sourceLessonId`标注原始课程编号，无需重新生成。

- `src/content.ts`：年级课程注册表（仅一年级开放，二至六年级为空）；`src/courses/grade-1/index.ts`和`extensions.ts`：题目、步骤、讲稿、互动问题、练习、方法和常见错误。新增课程通过同一数据结构扩展。
- `src/Scene.tsx`和`src/ExtraScenes.tsx`：基础SVG教学场景；`src/StoryboardScene.tsx`补充日历、分份线段、路程、成绩表、周期序列及原图计数，按步骤和音频播放进度渲染画面。
- `src/App.tsx`：年级/题型导航、播放器、课程/练习/小结、待复习列表。
- `src/progress.ts`：本机学习记录与答案校验。记录使用课程编号及版本，更新内容版本后不会沿用旧课程的结果。
- `public/audio/qwen3/`：240段Qwen3-TTS普通话音频及试听页，与部署一起发布，播放不需要实时语音API；原AAC文件保留作旧课程的回退资源。

每个讲解步骤独立音频；画面以音频`currentTime / duration`为时间基准，字幕按句长比例定位。暂停、拖动、倍速和重听使用同一播放时钟。自动连播在思考题处停下，答对后点击继续；任何步骤都可以手动跳转。字幕是句长估算的句级同步，后续可改成经人工标注的时间点。

## 一年级从基础到变化

根据《分类题目_含配图.docx》（2026-10-17）扩展。9节基础课保留，新增39节变化与原题课程；参考资料15道原题全部覆盖，其中三张三角形图拆成3节。共48课，每课5步，基础课3道练习，新增课1道配套练习，共66道。每类上方的学习路径可直接选课，最后一步也可继续下一种变化。每节课独立保存进度。

| 题型 | 节数 | 主要变化 |
| --- | ---: | --- |
| 植树 | 9 | 两端条件、圆形/三角形/长方形围圈、求间距、重复间距、物品宽度与空隙 |
| 归一 | 10 | 求份数、工人/机器与时间一起变、耽误时间、剩余路程、营地剩余食物 |
| 和差 | 3 | 求较小数、移动前后还原差 |
| 周期 | 5 | 星期周期、跨世纪、月历次数推理 |
| 平均数 | 4 | 缺少一份、人数与平均数、成绩表筛选 |
| 和差倍 | 4 | 和倍到差倍、折绳、输赢倒推 |
| 移多补少 | 3 | 倒推原数量、搬到倍数目标 |
| 图形计数 | 6 | 长方形、正方形、缺角网格、三种交叉三角形 |
| 年龄 | 4 | 过去时刻、两次倍数、过去到未来 |

4张原题PNG直接从Word提取，位于`public/images/reference-20261017/`，显示在对应题干下方并支持点击放大。`src/courses/reference-20261017.ts`保存原文、段落号及文件哈希，可用`python3 scripts/extract-reference-docx.py 路径/分类题目_含配图.docx`重新提取；图形动画保留原图线段连接与格线结构。L形格图按边长计数，三角形按包含/不包含最上顶点分类，支持切换分组、逐个查看和跟随音频。

封闭路线补充4课：圆形花坛（已给圆周长度）、三角形顶点去重、长方形围圈（配正方形练习）、已知树数反求间距。`src/PlantingLoopScene.tsx`用同一个播放时钟驱动沿边行走、逐棵种树与回到起点，顶点只显示一棵树。`pathOrder`只控制学习路径顺序；全局课程注册顺序保持稳定，以复用历史音频生成签名。

用户补充第31—36题已逐题加入归一问题，位于`src/courses/grade-1/compound-unit.ts`。前三题以人数/机器数×小时的格子表示同一效率，答案144、210、192个；后三题以1人1天的食物为1份，先扣除已吃部分，再按新人数重排，答案10、10、20天。`src/CompoundUnitScene.tsx`随音频播放逐格填入产量、消耗食物并重排剩余食物；食物小格按共同人数分组并标注份数，重排中绿色食物总量保持不变。每题含5步讲解、思考题、配套变式练习及5段Qwen3语音。

参考资料的原题难度较高，标为“原题挑战”，排在基础和条件变化之后，可以亲子共学。文档没有独立的和差、移多补少章节，这两类使用配套原创变式衔接。

## Qwen3-TTS 本地配音（默认）

采用 Qwen3-TTS 1.7B CustomVoice，Serena 中文女声，通过 MLX 在 Apple Silicon 上本地运行。模型只负责提前生成课程音频；网站发布后直接播放静态文件，不需要语音 API Key，也不需要为每次播放运行模型。

固定模型：`mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit`，版本 `41d3337e8b7f2843a75841595fc14e4b9a7a4b96`。模型遵循 Apache 2.0；来源：[Qwen 官方项目](https://github.com/QwenLM/Qwen3-TTS)、[MLX 模型卡](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit)。模型和解码器约3GB，缓存在本项目 `.cache/models/`，不会加入Git或发布到网站。

### 安装生成环境

需要Apple Silicon Mac和Python 3.12。前端开发不需要Python环境。

```sh
python3.12 -m venv .venv-tts
.venv-tts/bin/python -m pip install --cache-dir .cache/pip -r scripts/requirements-tts.txt
npm run audio:plan
.venv-tts/bin/python -u scripts/download-qwen-model.py
```

模型下载使用固定版本，支持分块续传并校验大文件SHA256。下载完成后，生成阶段使用本地模型，不调用云端语音服务。

### 试听、批量生成与安装

```sh
# 生成植树课程的读题和关系解释两段样片
npm run audio:sample

# 生成全部240段；中断后再次执行可以复用已完成音频；新增课程会复用未变更的已安装音频
npm run audio

# 用上一步输出的实际目录安装完整音频包
npm run audio:install -- .audio-output/qwen3-serena-实际目录

npm test
npm run build
```

生成过程中会持续保存 `.audio-output/qwen3-serena-.../checkpoint.json` 和 `index.html` 试听页。每段音频经过非静音、有限采样值和时长检查后才保存。全部240段完成后才产生可安装的 `catalog.json`。安装会核对模型版本、讲稿签名、文件SHA256、WAV格式和实际时长，全部通过后再一起切换音频及讲稿。失败或中断时，网站仍使用原有配音。

音频格式为24kHz、单声道、16位PCM WAV，文件名包含内容哈希，避免浏览器继续使用旧音频缓存。安装时也会复制试听页到 `/audio/qwen3/音频包编号/index.html`。`src/audio-catalog.json`记录当前实际使用的配音来源。

### 教学表达

- `scripts/speech-plan.ts`提供240段口语化讲稿，数字转换为中文读法。
- `scripts/qwen-plan.ts`提供Serena、标准普通话、亲切耐心的成年女老师讲述指令；不同步骤分别控制提问、看图解释和总结语气。
- 问题步骤在段尾保留1200ms停顿，其他步骤450ms；页面继续等待孩子作答。
- 画面和字幕以实际音频播放时钟为基准，保留暂停、倍速、重听与跳转。句内字幕仍按句长估算，尚未接入字级时间戳。
- `scripts/generate-qwen-audio.py`负责本地推理与可续跑音频包；`scripts/qwen-pack.ts`负责完整包校验和安装。

### 保留的其他生成器

原豆包接入作为可选工具保留：`npm run audio:doubao -- --dry-run`；真实调用需要单独配置 `.env.local`。原macOS系统配音工具为 `npm run audio:system`。默认生成流程使用Qwen3-TTS，两者不会自动作为失败回退服务。

## MVP 边界

- 学习记录保存在当前浏览器localStorage，不包含账号和跨设备同步。
- 看过答案的题计入待复习；重新练习可重置该题状态。
- 实际使用的语音由`src/audio-catalog.json`决定。生成新声音后需试听、核对数字读法及教学表达。
- 首批题目已通过独立算术校验，仍建议老师结合目标学生水平审核难度。
- 无实时AI对话、付费功能或管理后台。

## 本地运行（默认）

本项目当前仅需在本机运行，后续修改无需发布到托管平台。

```sh
../start.sh
../stop.sh
```

浏览器打开 http://127.0.0.1:5173/ 。服务只监听本机地址，无需登录。`start.sh`会先构建最新代码，再在后台启动，关闭终端后仍可使用；`stop.sh`会核对进程身份后停止本项目服务。重复执行安全，其他服务占用端口时会提示错误。PID和日志保存在 `.local-service/`，不加入Git。

课程音频已随静态文件保存在本地，播放不需要下载模型或调用语音服务。仍可用 `npm start` 在前台运行构建产物，或使用 `npm run dev` 开发并自动刷新。

`.openai/hosting.json`仅保留历史Sites身份；本地启动不使用这个配置。
